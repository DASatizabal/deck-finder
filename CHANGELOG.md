# Changelog

## [1.4.1] - 2026-09-23
### Changed
- Behind-the-scenes maintenance. Nothing changes in how the app works.

## [1.4.0] - 2026-09-23
### Added
- Deck plans for Norwegian Joy and Norwegian Aqua (Decks 5 to 20), each with an "On this deck" list.
- A version number and a "What's new" screen in the menu.
- The app now tells you when an update is available and updates itself when you tap the notice.

## [1.3.0] - 2026-09-23
### Added
- Pinch with two fingers to zoom in and out of deck plans.

## [1.2.0] - 2026-09-23
### Changed
- Itinerary lookup now asks NCL directly. The Cloudflare Worker is only used as a backup.

## [1.1.0] - 2026-09-23
### Added
- Trip Set Up: add several trips, pick the active trip, and set the sail date and cabin.
- Itinerary lookup, a trip strip at the top of the screen, and a cabin pin you place by tapping the plan.

## [1.0.0] - 2026-09-23
### Added
- First installable app that works offline: Norwegian Getaway Decks 5 to 18, deck slider, "On this deck" lists, search, and cabin pin.
